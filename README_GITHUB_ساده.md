# سما ۳۶۰ — نسخه اندروید ۸.۰

## فقط با گوشی اجرا کنید

### ۱) ساخت Repository
در GitHub یک Repository با نام `SAMA360-Android` بسازید.

### ۲) بارگذاری
در Repository:
Add file → Upload files

تمام فایل‌ها و پوشه‌های همین پروژه را بارگذاری کنید، نه فایل ZIP را.

### ۳) ثبت
Commit changes را بزنید.

### ۴) ساخت APK
به تب Actions بروید.
Workflow «ساخت APK سما ۳۶۰» را انتخاب کنید.
Run workflow را بزنید.

### ۵) دریافت APK
بعد از سبز شدن Build، وارد همان اجرای موفق شوید.
در قسمت Artifacts فایل `SAMA360-APK` را دانلود کنید.
فایل APK را روی گوشی باز و نصب کنید.

این نسخه برای تست موبایلی آماده است. اتصال به سرور مرکزی SAMA 360 باید در مرحله استقرار عملیاتی تنظیم شود.
