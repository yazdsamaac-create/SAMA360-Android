# SAMA 360 v8.0 — ساخت APK ابری بدون کامپیوتر

## روش پیشنهادی
این پروژه برای GitHub Actions آماده شده است. پس از قرار دادن فایل‌ها در یک مخزن GitHub، سرویس ابری GitHub Actions روی سرور خودش APK را می‌سازد؛ بنابراین نصب Android Studio روی گوشی لازم نیست.

## مراحل فقط با گوشی
1. وارد GitHub شوید و یک Repository جدید بسازید، مثلاً `SAMA360-Android`.
2. فایل ZIP این بسته را از حالت فشرده خارج کنید.
3. محتویات آن را در Repository قرار دهید.
4. وارد تب **Actions** شوید.
5. گردش‌کار **SAMA 360 Android APK** را انتخاب کنید.
6. گزینه **Run workflow** را بزنید.
7. صبر کنید تا وضعیت Build سبز شود.
8. وارد همان اجرای موفق شوید.
9. در بخش **Artifacts** فایل `SAMA360-v8.0-debug-apk` را دریافت کنید.
10. فایل APK را روی همین گوشی دانلود و نصب کنید.

## اگر Actions به‌صورت خودکار اجرا شد
با هر Push به شاخه main نیز Build اجرا می‌شود.

## خروجی
`app/build/outputs/apk/debug/app-debug.apk`

## نکته مهم
این Build یک APK قابل نصب برای آزمایش است. برای نسخه عملیاتی سازمانی باید API مرکزی، احراز هویت، پایگاه داده، HTTPS، اعلان‌ها و سرویس‌های رسانه‌ای واقعی به آن متصل شوند.

## وضعیت سرویس‌های ابری
در سال 2026 وضعیت Firebase Studio تغییر کرده و ایجاد Workspace جدید برای کاربران جدید غیرفعال شده است؛ بنابراین این بسته به GitHub Actions متکی است و وابسته به Firebase Studio نیست.
